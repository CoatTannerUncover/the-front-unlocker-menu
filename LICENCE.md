## 🧩 About

**The Front Companion** is a curated list of The Front open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, base tracker
- **Quality-of-Life Helpers** — crafting catalog, loot notes, inventory overlay
- **Research Notes** — base layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Overlay — track nearby materials and loot spots
- Base Planner — map notes for base layouts
- Crafting Notes — recipe and station reference
- Map Radar — proximity notes for study (single-player)

### Wallhack
- Item Catalog — browse gear, weapons, attachments
- Loadout Notes — organize builds and cosmetics
- Inventory Overlay — quick reference panel

### Aimbot
- Sandbox Notes — experiment with layouts on your own server
- Build Helper — grid and placement reference
- Travel Notes — route planning for exploration
